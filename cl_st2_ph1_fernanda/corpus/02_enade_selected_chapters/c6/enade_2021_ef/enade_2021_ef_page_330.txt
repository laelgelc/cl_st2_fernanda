6.3.1.6 ANÁLISE DE LÍNGUA PORTUGUESA DAS QUESTÕES DISCURSIVAS DO COMPONENTE 
DE FORMAÇÃO GERAL 
Os dados obtidos a partir das respostas à Questão Discursiva do Componente de 
Formação Geral de Educação Física desagregados por Grande Região, segundo Habilitação 
e Modalidade de Ensino, no que tange à Língua Portuguesa, encontram-se na Tabela 6.16 e 
no Gráfico 6.9. 
Nos cursos de Licenciatura em Educação Física, a Média desse aspecto foi 42,0, 
inferior à obtida pelos alunos de Bacharelado (39,7). Quando se considera a Modalidade de 
Ensino para cada Habilitação, os alunos de cursos Presenciais de Licenciatura obtiveram 
Média 43,2. A Média com respeito à Língua Portuguesa foi menor para os alunos de cursos a 
Distância (40,5). Para os cursos de Bacharelado, os valores foram: 40,3 para os cursos 
Presenciais, e 38,6 para os cursos a Distância. A Mediana das notas de Língua Portuguesa 
para os cursos de Licenciatura foi 47,5, para o total e para os cursos Presenciais, e menor 
para os a Distância, 45,0. Para os cursos de Bacharelado, a Mediana foi 45,0, para o total e 
para os cursos Presenciais, e menor para o Bacharelado a Distância, 42,5. A nota Máxima 
não chegou a 100,0 para nenhuma combinação de Habilitação e Modalidade.
