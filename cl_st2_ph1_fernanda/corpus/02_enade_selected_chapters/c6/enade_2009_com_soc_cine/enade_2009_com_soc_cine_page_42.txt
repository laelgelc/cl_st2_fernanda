3.2 Análise das Questões Objetivas 
3.2.1 Formação Geral 
A Tabela 3.4 apresenta as estatísticas básicas relativas às oito questões objetivas da 
Formação Geral dos estudantes. Adiantamos que a primeira questão foi desconsiderada 
pelo critério da correlação ponto-bisserial.  
Como pode ser observado na Tabela 3.4, os estudantes concluintes obtiveram 
desempenho inferior, com nota média de 50,32, em relação aos estudantes ingressantes 
cuja nota média foi 52,54. A variabilidade entre os concluintes foi um pouco maior do que 
entre os ingressantes, como indicaram os desvios-padrão de 24,5, para o grupo de 
ingressantes e 29,4 para o grupo dos concluintes. A amplitude total das notas foi a mesma 
para ambos os grupos: nota mínima de 0,00 e máxima de 85,7. A mediana foi igual para 
ambos os grupos: 57,1. A assimetria, medida pelo coeficiente de assimetria (skewness) foi 
um pouco maior em módulo para os ingressantes (-0,7) do que para os concluintes (-0,6), 
ainda que ambos fossem negativos indicando uma assimetria para a direita, fato reforçado 
pelos valores menores das médias dos dois grupos quando comparados à mediana 
correspondente.
