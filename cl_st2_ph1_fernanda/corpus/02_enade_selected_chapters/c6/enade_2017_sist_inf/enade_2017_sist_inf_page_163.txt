Ainda em relação à escolha de uma estrutura de dados diferente de matriz e de lista, 
alguns estudantes propuseram organizar as áreas de plantio segundo um grafo. Embora essa 
estrutura seja viável, ela é complexa demais para resolver um problema simples. Dessa forma, 
quase todos os estudantes que propuseram um grafo como estrutura não apresentaram 
algoritmo algum para percorrê-lo. Alguns poucos esboçaram algoritmos com altíssimo nível 
de abstração. 
Dentre os tipos de respostas que obtiveram as notas mais baixas, vale destacar as 
que: 
- propuseram estruturas de dados totalmente inadequadas, como fila e pilha; 
- usaram comandos SQL; 
- foram elaboradas por meio de pseudocódigo extremamente abstrato; 
- não empregaram comandos de repetição para percorrer a estrutura escolhida; 
- usaram uma narrativa para descrever uma solução para o problema. 
As respostas insuficientes foram, em geral, tentativas de descrever por meio de texto 
em prosa o algoritmo escolhido. Dessa forma, esses estudantes receberam nota zero no item 
‘a’. 
Os estudantes que apresentaram respostas medianas podem ser divididos em duas 
categorias: os que escolheram a estrutura de dados adequada, mas apresentaram algoritmos 
inadequados para percorrê-la e os que apresentaram uma estrutura de dados inadequada, 
mas apresentaram um algoritmo correto, ou quase correto, para percorrer uma matriz. 
As boas respostas apontaram que a estrutura de dados adequada deveria ser uma 
matriz, uma tabela ou um array bidimensional, e apresentaram um algoritmo correto para 
percorrer a estrutura escolhida.
