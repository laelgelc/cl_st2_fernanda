3.2 Análise das Questões Objetivas 
 
3.2.1 Formação Geral 
A Tabela 3.4 apresenta as estatísticas básicas relativas às oito questões objetivas da 
Formação Geral dos estudantes. Adiantamos que a primeira questão foi desconsiderada 
pelo critério da correlação ponto-bisserial.  
Como pode ser observado na Tabela 3.4, os estudantes concluintes obtiveram 
desempenho superior, com nota média de 61,69, em relação aos estudantes ingressantes 
cuja nota média foi 58,33. A variabilidade entre os concluintes foi maior do que entre os 
ingressantes, como indicaram os desvios-padrão de 24,0, para o grupo de ingressantes e 
24,8 para o grupo dos concluintes. A amplitude total das notas foi a mesma para ambos os 
grupos: nota mínima de 0 e máxima de 100. A mediana foi 57,1 para os ingressantes e 71,4 
para os concluintes. A assimetria, medida pelo coeficiente de assimetria (skewness) foi um 
pouco maior em módulo para os concluintes (-0,7) do que para os ingressantes (-0,3), ainda 
que ambos fossem negativos indicando uma assimetria para a esquerda.
