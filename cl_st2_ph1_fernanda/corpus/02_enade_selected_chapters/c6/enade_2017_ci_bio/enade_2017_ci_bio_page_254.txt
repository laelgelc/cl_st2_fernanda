6.3.2 Componente de Conhecimento Específico 
As estatísticas básicas das notas referentes às questões discursivas do Componente 
de Conhecimento Específico de Ciências Biológicas Licenciatura por Grande Região, segundo 
Modalidade de Ensino, estão disponibilizadas na Tabela 6.17a. As informações equivalentes 
para o Bacharelado estão na Tabela 6.17b. Observa-se que as Médias foram bem mais baixas 
do que para as questões discursivas do Componente de Formação Geral. Enquanto no 
Componente de Formação Geral as Médias para estudantes de Ciências Biológicas de 
Licenciatura foram, respectivamente para os de Ensino Presencial e a Distância, 58,0 e 54,3 
(57,4 para o total), na parte de Conhecimento Específico as Médias foram 35,4 e 32,6 (34,9 
para o total). Como já comentado, não foram observados cursos a Distância de Bacharelado. 
Para os cursos Presenciais de Bacharelado, as médias equivalentes foram 60,6 para as 
discursivas de Formação Geral e 23,2 para as de Conhecimento Específico. 
Para os cursos de Licenciatura, a nota Máxima foi maior para os cursos Presenciais 
(100,0) do que para os a Distância (96,7). Para os cursos Presenciais de Bacharelado, a nota 
Máxima foi 100,0. As notas mínimas foram zero para todas as combinações de Habilitação e 
Modalidade de Ensino.
