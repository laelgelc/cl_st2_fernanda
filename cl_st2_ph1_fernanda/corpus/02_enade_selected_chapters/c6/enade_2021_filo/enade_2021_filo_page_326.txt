6.3.1.6 ANÁLISE DE LÍNGUA PORTUGUESA DAS QUESTÕES DISCURSIVAS DO COMPONENTE 
DE FORMAÇÃO GERAL 
Os dados obtidos a partir das respostas à Questão Discursiva do Componente de 
Formação Geral de Filosofia desagregados por Grande Região, segundo Habilitação e 
Modalidade de Ensino, no que tange à Língua Portuguesa, encontram-se na Tabela 6.16 e no 
Gráfico 6.9. 
Nos cursos de Licenciatura em Filosofia, a Média desse aspecto foi 51,9, superior à 
obtida pelos alunos de Bacharelado (49,4). Quando se considera a Modalidade de Ensino 
para cada Habilitação, os alunos de cursos Presenciais de Licenciatura obtiveram Média 51,7. 
A Média com respeito à Língua Portuguesa foi maior para os alunos de cursos a 
Distância (52,1). Para os cursos de Bacharelado, os valores foram: 49,0 para os cursos 
Presenciais, e 51,8 para os cursos a Distância. A Mediana das notas de Língua Portuguesa 
para os cursos de Licenciatura foi 57,5 para ambas as Modalidades. Para os cursos de 
Bacharelado, a Mediana foi 52,5, para o total e para os cursos Presenciais, e maior para o 
Bacharelado a Distância, 55,0. A nota Máxima não chegou a 100,0 para nenhuma combinação 
de Habilitação e Modalidade.
