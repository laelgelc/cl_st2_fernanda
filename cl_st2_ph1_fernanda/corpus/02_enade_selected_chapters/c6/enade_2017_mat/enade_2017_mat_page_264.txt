6.3.2 Componente de Conhecimento Específico 
As estatísticas básicas das notas referentes às questões discursivas do Componente 
de Conhecimento Específico de Matemática Licenciatura por Grande Região segundo 
Modalidade de Ensino, estão disponibilizadas na Tabela 6.17a. As informações equivalentes 
para o Bacharelado estão na Tabela 6.17b. Observa-se que as Médias foram bem mais baixas 
do que para as questões discursivas do Componente de Formação Geral. Enquanto no 
Componente de Formação Geral as Médias para estudantes de Matemática de Licenciatura 
foram, respectivamente para os de Ensino Presencial e a Distância, 49,6 e 52,0 (50,3 para o 
total), na parte de Conhecimento Específico as Médias foram 33,7 e 28,8 (32,4 para o total). 
Já para os cursos de Bacharelado, as médias equivalentes foram 49,8 e 70,9 (50,1 para o 
total) para as discursivas de Formação Geral e 38,4 e 8,3 (37,9 para o total) para as de 
Conhecimento Específico. 
Para os cursos de Licenciatura, a nota Máxima foi 100,0 para os cursos Presenciais e 
a Distância. Para os cursos de Bacharelado a nota Máxima foi 100,0 para os presenciais e 
para a modalidade a Distância. As notas mínimas foram zero para todas as combinações de 
Habilitação e Modalidade de Ensino.
