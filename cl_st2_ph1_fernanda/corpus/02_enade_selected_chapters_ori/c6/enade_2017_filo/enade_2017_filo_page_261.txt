6.3.2 Componente de Conhecimento Específico 
As estatísticas básicas das notas referentes às questões discursivas do Componente 
de Conhecimento Específico de Licenciatura em Filosofia, por Grande Região, segundo 
Modalidade de Ensino estão disponibilizadas na Tabela 6.17a. As informações equivalentes 
para o Bacharelado estão na Tabela 6.17b. Observa-se que as Médias foram bem mais baixas 
do que para as questões discursivas do Componente de Formação Geral. Enquanto no 
Componente de Formação Geral as Médias para estudantes de Filosofia de Licenciatura 
foram, respectivamente para os de Ensino Presencial e a Distância, 55,8 e 54,4 (55,3 para o 
total), na parte de Conhecimento Específico as Médias foram 28,3 e 19,5 (25,1 para o total). 
Já para os cursos de Bacharelado, as médias equivalentes foram 55,2 e 68,3 (55,9 para o 
total) para as discursivas de Formação Geral e 26,1 e 35,0 (26,6 para o total) para as de 
Conhecimento Específico. 
Para os cursos de Licenciatura, a nota Máxima foi maior para os cursos Presenciais 
(100,0) do que para os a Distância (96,7). Também para os cursos de Bacharelado, a nota 
Máxima foi maior para os cursos presenciais (100,0) do que para os a Distância (83,3). As 
notas mínimas foram zero para todas as combinações de Habilitação e Modalidade de Ensino.
