3.2 Análise das Questões Objetivas 
3.2.1 Formação Geral 
A Tabela 3.4 apresenta as estatísticas básicas relativas às oito questões objetivas da 
Formação Geral dos estudantes. Adiantamos que a primeira questão foi desconsiderada 
pelo critério da correlação ponto-bisserial.  
Como pode ser observado na Tabela 3.4, os estudantes concluintes obtiveram 
desempenho superior, com nota média de 53,94, em relação aos estudantes ingressantes, 
cuja nota média foi 49,69. A variabilidade entre os concluintes foi cerca de 1% menor do 
que entre os ingressantes, como indicaram os desvios-padrão de 21,9, para o grupo de 
ingressantes e 22,2 para o grupo dos concluintes. A amplitude total das notas foi a mesma 
para ambos os grupos: nota mínima de 0 e máxima de 100. A mediana foi 57,1 para os 
concluintes e 42,8 para os ingressantes. A assimetria, medida pelo coeficiente de assimetria 
(skewness) foi um pouco maior em módulo para os ingressantes (0) do que para os 
concluintes (-0,1), ainda que ambos fossem muito similares, este coeficiente indicou que a 
distribuição de notas dos ingressantes foi mais simétrica do que a dos concluintes.
